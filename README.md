# On joue à quoi ce soir ?

Petite appli pour tirer au sort un jeu parmi la ludothèque du bar à jeux Débit de Jeux, selon le nombre de joueurs, la durée et l'envie du moment.

Un seul fichier `index.html`, sans dépendance ni build. Les réglages (jeux écartés, jeux ajoutés, filtres) sont stockés en `localStorage` sur l'appareil.
